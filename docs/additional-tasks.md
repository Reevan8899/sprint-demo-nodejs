# Дополнительные задания A и F

## A. Интерактивный rebase
Ветка `feature/order-history`, PR #9.
До операции: пять коммитов, в том числе `fix`, `wip`, `update`.

```bash
git log --oneline origin/sprint-1..HEAD
git rebase -i origin/sprint-1
git commit --amend -m "feat(orders): add tested order history API and docs"
git push --force-with-lease origin feature/order-history
git log --oneline origin/sprint-1..HEAD
```

В интерактивном todo сохранён первый pick, остальные четыре изменены на fixup (вариант объединения без сохранения мусорных сообщений). Редактор todo автоматизирован; выполнена именно команда `git rebase -i`. В PR число коммитов изменилось с 5 на 1. Перед дальнейшим merge ветка дополнительно синхронизирована с обновившимся sprint-1; поэтому её более поздняя история может содержать интеграционный коммит. Снимки до/после относятся к моменту rebase.

Force push использован только для своей feature-ветки и с `--force-with-lease`. Общие ветки не переписывались.

## F. Заблокированная задача
Issue #4 имела метку `blocked` и зависела от корзины (Issue #3, PR #8). Разработка checkout началась после успешного merge PR корзины в sprint-1. Метка снята; новый checkout создан от актуальной sprint-1 и использует настоящий API `getCart`/`clearCart`.

Решение: изменение порядка работы. Пока зависимость не готова, выполнялись независимые задачи (авторизация, каталог, история). Стабы и парное программирование не использовались. История метки сохраняется в timeline Issue.
