# Sprint 1: MVP интернет-магазина

## Sprint Goal
Реализовать регистрацию и вход, просмотр каталога, корзину, оформление заказа и историю заказов. Продемонстрировать полный сценарий покупки из консоли.

## Формат и роли
Индивидуальная учебная имитация: Reevan8899 совмещает Product Owner, Scrum Master и Developer. Несуществующие участники не заявляются.

## Definition of Done
- Реализованы критерии приёмки Issue.
- Код запускается на Node.js 24, проверка синтаксиса проходит.
- Есть позитивные и негативные модульные тесты; все тесты проходят.
- Выполнена документированная самопроверка, замечания обработаны.
- PR связан с Issue и объединён в sprint-1; CI успешен.
- Обновлена документация.

В командном варианте дополнительно требуется независимое ревью коллеги. Самопроверка не заменяет его.
