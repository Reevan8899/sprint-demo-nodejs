# Sprint Demo: интернет-магазин на Node.js

![CI](https://github.com/Reevan8899/sprint-demo-nodejs/actions/workflows/pr-check.yml/badge.svg)

Учебная индивидуальная имитация Scrum-спринта. Автор: Reevan8899.
Node.js 24+, без внешних зависимостей. Данные хранятся в памяти до завершения процесса.

## Функциональность
### Аутентификация
Регистрация и вход по email.

### Каталог
Три товара с ценами и поиск по ID.

### Корзина
Добавление товаров, объединение количества, подсчёт суммы и очистка.

### Оформление заказа
Проверка адреса, сохранение снимка заказа и очистка корзины.

### История заказов
Поиск заказа по ID и фильтрация по минимальной сумме.

## Запуск
```bash
npm ci
npm run check
npm test
npm run coverage
npm run demo
```

Это учебная библиотека с CLI-демонстрацией. Все пять модулей интегрированы. Цены - целые рубли; хранение данных в памяти. Аутентификация не ограничивает остальные модули и не реализует HTTP-сессии.

## Процесс
`feature/* -> sprint-1 -> main`. Фичи объединяются через Pull Request.
Цель и критерии: [docs/sprint-1-goal.md](docs/sprint-1-goal.md).
